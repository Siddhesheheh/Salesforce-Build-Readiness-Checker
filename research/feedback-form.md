# Feedback form (Google Form, 2-3 minutes)

Intro text: "Thanks for trying the Salesforce Build Readiness Checker. Please use a sample or sanitized requirement only. No client data."

## Section A: About you
1. Your role. (Developer / Architect / Admin / BA / PM-PO / Other)
2. Salesforce projects in the last 12 months. (0 / 1-2 / 3-5 / 6+)
3. What did you test? (Provided sample / My own sanitized requirement)

## Section B: Ratings (1 = strongly disagree, 5 = strongly agree)
4. The findings were relevant to my requirement.
5. The findings were specific, not generic.
6. The severity ratings (Blocker / Important / Minor) felt right.
7. The questions are ones I would send to a BA/PM, or answer as one.
8. I trust the verdict.

## Section C: Value
9. How many gaps did it find that you had not noticed? (0 / 1 / 2-3 / 4+)
10. Did it miss an important gap? Which one? (open)
11. Did any finding feel wrong or made up? Which one? (open)
12. How likely are you to run this before kickoff on a real project? (1-5)
13. Would the "verify in the org" checks help you? (Yes / Somewhat / No)

## Section D: Open
14. The most useful thing in the report was...
15. The most confusing or least useful thing was...
16. What would you need to see before relying on this in real work?

## Section E: Permission
17. May we quote your feedback anonymously? (Yes / No)
18. Can we follow up in a week? (Yes / No; email if yes)

## Metric mapping
| Deck number | Question |
|---|---|
| Relevance, specificity, severity, question quality, trust | Q4-Q8 averages |
| Gaps not noticed | Q9 (share answering 1 or more) |
| Intent to use | Q12 (share answering 4-5) |
| Verify-in-org value | Q13 |
| Misses and false alarms | Q10, Q11 |
| Quotes | Q14-Q16 |

## Blind comparison (5-8 people, separate short form)
Show the same requirement's review from this tool (A) and a generic AI chat (B), randomized and unlabeled. Ask: Which is more useful? Which would you trust more? Which would you send to the BA as is? What did one miss that the other caught?

## One-week follow-up (2 questions)
1. Did you use any finding or question in a real conversation or project? What happened?
2. Have you used the tool again? Why or why not?
